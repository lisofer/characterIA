Voz a partir de una muestra

Subí una muestra con voz clara, sin música, de 3 a 30 segundos. La convertimos automáticamente a WAV y Fish recibirá sus datos de audio reales. El texto debe coincidir palabra por palabra con la muestra. Si no cargás una muestra, se usará el ID de voz configurado.

03 / IDENTIDAD VISUAL

Tu personaje animado

0 de 8 imágenes cargadas

Cargá 8 PNG del mismo tamaño y encuadre. Primero reposo, después A, O y E; cada posición tiene ojos abiertos y cerrados.

Formatos aceptados: PNG transparente · Máximo 5 MB por imagen. Cada imagen se guarda al subirla.

Encuadre del personaje

Cargá el PNG de reposo para previsualizar el encuadre.

Primero probá con tamaño 100 % y posición centrada. Si un PNG tiene mucho margen transparente, ajustá los valores sin cambiar el archivo.
